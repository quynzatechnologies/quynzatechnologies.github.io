Curso de Programación en MicroPython con ESP32

Programa de formación técnica orientado al desarrollo de sistemas embebidos utilizando MicroPython sobre el microcontrolador ESP32.

Aprende a programar hardware real, interactuar con sensores y actuadores, y construir proyectos funcionales que sirven como base para aplicaciones IoT y mecatrónicas.

Contenido Destacado

Programación en Python

Introducción a los fundamentos del lenguaje Python con enfoque en lógica, estructuras de control y buenas prácticas aplicadas a sistemas embebidos.

Programación con Micropython

Desarrollo de aplicaciones embebidas en el ESP32 utilizando MicroPython, accediendo directamente a pines, periféricos y recursos del microcontrolador.

Sensores y Actuadores

Interacción práctica con sensores y actuadores reales para adquisición de datos, control de dispositivos y automatización básica.

Experimentos Prácticos

Ejercicios guiados que permiten comprender el comportamiento del hardware y el software mediante pruebas reales y resultados observables.

Proyecto Final

Desarrollo de un proyecto funcional que integra programación, hardware y control, consolidando los conocimientos adquiridos durante el curso.

Beneficios para los Participantes

Desarrollo de Habilidades Clave

Adquiere habilidades prácticas en programación de microcontroladores, control de hardware y desarrollo de sistemas embebidos.

Aplicación Inmediata

Desde las primeras sesiones podrás desarrollar y probar tus propios programas directamente sobre el ESP32.
